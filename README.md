# Road Accident and Casualty Pattern Analysis

## Project Overview
This project focuses on analysing road accident
and casualty patterns using Power BI.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Project Objectives
- Analyse road accident data.
- Identify accident and casualty trends.
- Understand accident patterns.
- Create interactive dashboards.

## Key Features
- Interactive dashboards
- Data visualization
- Filters and slicers
- Trend analysis

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development
